# Image prompt patterns

Reusable AI image prompt patterns with real results, for any image generator.

Curated by the [pixexid team](https://pixexid.com/).

## How to use a pattern

1. Pick the pattern that matches the picture you need.
2. Copy its template and fill every `[slot]` with your own subject, setting and wording.
3. Compare your result with the examples on the pattern page. Each example links to its full prompt.
4. If the result misses, read the common failures on the pattern page before rewording everything.

## Patterns

- [Product photo brief](patterns/product-photo-brief.md): a fictional product, a set, one light direction and a blank surface.
- [Character reference sheet](patterns/character-reference-sheet.md): keep one character recognizable across new scenes.
- [Transparent cutout](patterns/transparent-cutout.md): a finished artwork on real transparency, with no background.
- [Poster with lettering](patterns/poster-with-lettering.md): one large word as the main shape of the poster.
- [Style transfer](patterns/style-transfer.md): change the medium and keep the subject the same.
- Photo restoration request: examples coming. No reviewed case exists yet.

## Guides

- [Prompt vocabulary](guides/prompt-vocabulary.md): lighting, lens, composition, material and print terms, each tied to a real prompt.

## Tested on

Every example was made with the generator named on its case page: GPT Image 2.5, with the exact backend variant not exposed. We have not run these prompts on other generators, so they may need small changes there. No seed, quality setting or cost is claimed because those values were not exposed.

## Community comparisons

Ran one of these prompts on another generator? Add a comparison with a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Use the catalogue

The machine-readable [catalogue](data/cases.json), its [CSV export](data/cases.csv) and the [schema](schema/cases.schema.json) drive every case page and the counts above. Refresh and verify the export with:

```sh
node scripts/export.mjs
node --test scripts/*.test.mjs
node scripts/validate.mjs --links
```

`node scripts/export.mjs --offline` rebuilds the pages and CSV from `data/cases.json` without fetching.
